# 2026-11-07

## 新建《方寸食光 / Food & Table》项目官网（纯前端静态站）

- 目标仓库：`https://github.com/Cimk3/A-Bite-of-Time`，Minecraft 基岩版创造模式场景装饰附加包，MIT，当前 v0.8.6 / `0.8.6-release.1`。
- 技术栈：Vite 6 + Vue 3（`<script setup>`）+ TypeScript + vue-router（Hash 模式）+ 原生 CSS；无后端、无 UI 组件库。`src/utils/dom.js` 是纯 JS 工具层（滚动动效、复制、锚点），配套 `.d.ts` 类型声明。
- 三个页面：`src/views/HomeView.vue`（首页）、`DownloadView.vue`（下载页）、`DocsView.vue`（说明页）；共享组件在 `src/components/`，设计令牌与样式在 `src/styles/{base,components,pages}.css`。
- 所有文案数据集中在 `src/data/site.ts`：版本、5 个 Release 附件的真实 SHA-256、9 个历史版本、13 条 `/function mcpe_food/` 命令、菜品统计、FAQ、文档链接。内容依据仓库 README / docs / v0.8.6 Release 页面整理，未臆造。
- 视觉：深墨绿 + 暖金，取自项目离线预览图底色；23 张预览图从仓库 `previews/` 下载到 `public/previews/`。站内明确标注这些是离线 UV／色图预览，不是游戏内截图。
- 交互：画廊分类 Tab、图片灯箱（ESC / 方向键）、命令一键复制 + Toast、说明页 Sticky 目录滚动高亮、命令筛选、FAQ 折叠、移动端汉堡菜单、回到顶部。
- 部署相关：`vite.config.ts` 设 `base: './'` + Hash 路由，便于 GitHub Pages 子路径；`npm run dev` / `build`（含 `vue-tsc` 类型检查）/ `preview`。产物在 `dist/`。
- 验证：`npm run build` 零错误通过；用 puppeteer-core + 本机 Chrome 在 390px 与 1440px 真实视口验证，`documentElement.scrollWidth` 等于视口宽度、无横向溢出；Tab 切换、灯箱开关、复制 Toast、命令筛选（13→3）、FAQ 展开、目录跳转、移动端菜单均正常，无 console / pageerror。
- 注意：Chrome headless 直接 `--window-size=390` 会被钳制到约 500px 造成"截图被裁"假象，测移动端必须用 CDP 的 `Emulation.setDeviceMetricsOverride`（puppeteer `setViewport`）。
